# BotZone

بات‌زون — ربات‌های هوشمند سروش

Modern dark UI homepage built with React + Vite + Tailwind.

## Development

```bash
npm install
npm run dev
npm run build
```

## GitHub Pages

This site is deployed via GitHub Pages:

- **Live URL**: https://Amogrotex.github.io/BotZone/
- Source: `main` branch, `/docs` folder
- Built file: single-file `index.html` (265KB) with inlined JS/CSS via `vite-plugin-singlefile`

To update: extract zip, run `npm run build`, copy `dist/index.html` to `docs/index.html`.

Zip original: `modern-dark-ui-homepage.zip`
